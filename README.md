## Descripción

Plan Mejoramiento es una aplicación Android desarrollada en Kotlin que permite ingresar una nota, validarla y clasificarla según su resultado.

La aplicación permite:

* Ingresar una nota entre 0 y 5.
* Validar que el campo no esté vacío.
* Validar que la nota esté dentro del rango permitido.
* Clasificar la nota como **Excelente**, **Aprobado** o **No aprobado**.
* Mostrar el resultado en una segunda pantalla.

## Tecnologías utilizadas

* Kotlin
* Android Studio
* XML
* ViewBinding
* Android Activities
* Intent
